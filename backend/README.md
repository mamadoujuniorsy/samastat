# SamaStat — backend

API NestJS. Voir le README à la racine du monorepo pour le démarrage, l'architecture et le
principe de non-invention des valeurs.

Scripts utiles :

```bash
npm run start:dev     # API en mode watch sur le port défini par PORT (3001)
npm run db:migrate    # applique src/database/migrations/*.sql
npm run db:seed       # charge src/database/seed/indicators.json
npm test              # vitest
```
